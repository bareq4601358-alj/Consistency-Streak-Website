# Streak — Daily Wins

A premium streak tracker with a flip-calendar UI. Tap any day to mark it complete (solid green flip). Your current streak shows beside the calendar with a fire emoji.

## Features

- Monthly calendar with 3D flip animation on day tap
- Current streak counter with animated flame
- Stats: this month, best streak, all-time, completion rate
- Monthly progress bar
- Local storage — your data persists in the browser
- Month navigation (prev / next)
- Milestone toasts at 7-day and 30-day streaks

## Run locally

Open `index.html` in your browser, or:

```bash
npx serve .
```

Then visit `http://localhost:3000`.
